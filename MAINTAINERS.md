# Maintainers

| Maintainer | Role | Responsibility |
| --- | --- | --- |
| [Amal David](https://github.com/Amal-David) (`@Amal-David`) | Project and security maintainer | Architecture, contribution review, vulnerability coordination, dependency-security review, and release approval. |

Private security reports go through [SECURITY.md](SECURITY.md), not public issue
comments. Technical boundaries are documented in
[docs/SECURITY_MODEL.md](docs/SECURITY_MODEL.md).

[CODEOWNERS](.github/CODEOWNERS) records the requested reviewer for repository
changes. It does not itself enable required reviews or branch protection.
Maintainer identity is separate from independent adoption: stars, forks,
first-party fixtures, and unmerged integrations must not be represented as
verified downstream usage.
