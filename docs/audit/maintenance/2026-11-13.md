## Finding addressed

The Poetry graph locked Soup Sieve 2.10, which matched
[GHSA-mmhr-3c5m-f64f](https://github.com/advisories/GHSA-mmhr-3c5m-f64f),
published on 2026-11-13. The reviewed advisory describes polynomial CPU use when
descendant-combinator selectors are matched against deeply nested untrusted HTML.
KeyLeak parses untrusted HTML with Beautiful Soup but its application paths use
`find_all`, not Soup Sieve's `select`, `select_one`, or user-controlled selector
compilation; exploitability in KeyLeak was not established. The exact advisory
match was nevertheless removed by selecting Soup Sieve 4.1 in both Python
manifests and `requirements.txt`, then regenerating the lock. Version 4.1 is the
current stable, provenance-backed PyPI release, supports the repository's Python
range, and contains the upstream caching fix. The major-version selector semantic
changes were reviewed; current KeyLeak call sites do not use those selector APIs.
