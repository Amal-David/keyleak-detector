## Findings addressed

- The development-only REA/Ghidra graph resolved `glob` 13.0.6 and `minimatch`
  10.2.6. They matched GHSA-3g3m-2fjr-6pw4 and GHSA-g3hv-75wg-m249,
  respectively. Both are resource-consumption/availability issues. No production
  reachability or credential impact was established. Exact overrides now select
  the documented first fixed versions, `glob` 14.0.2 and `minimatch` 11.0.1.
- The extension offered one-click provider calls using detected credentials, and
  legacy remediation text encouraged equivalent manual calls. This lacked an
  ownership/authorization gate and conflicted with the disclosure policy. All
  provider-network credential validation and credential-testing commands were
  removed. The popup retains local JWT claim inspection only; it does not verify
  signatures or contact an issuer. Focused Python and Node regressions prevent
  those network testers and unsafe recommendations from returning.

registry metadata. Before the fix, 170 OSV queries returned only the two matches
above. After lock regeneration, 171 queries returned no matches. All Poetry
artifact hashes and all 143 npm integrity values matched registry metadata; no
selected PyPI artifact was yanked, no selected npm package was deprecated, and
registry metadata declared no install lifecycle hook in the npm graph.

The changed npm artifacts use the same established maintainer identity as their
predecessors and have verified registry signatures. `npm audit` returned zero
known vulnerabilities; the installed graph had 138 verified registry signatures
and 27 provenance attestations. These checks are point-in-time metadata evidence,
not proof of upstream implementation safety. Exact versions, advisory IDs,
integrities, and lock hashes are recorded in the
[dependency snapshot](2026-11-06-dependencies.json).

PyJWT remained at 2.15.1 because it was already the current selected stable
release and had no advisory match. Broader direct-dependency upgrades were not
taken without a security need and compatibility review. The separately resolved
installed-wheel and PHP deployment graphs produced no OSV matches after excluding
the environment's packaging bootstrap tools.

## Reviewed boundaries and remaining limits

authorization/active-probe gates, archive/path/link budgets, deserialization and
subprocess call sites, extension/native-host messaging, Actions permissions,
`action.yml`, Docker, deployment, packaging, and release paths were reviewed.

was tested. Synthetic fixtures are not exposed credentials.
