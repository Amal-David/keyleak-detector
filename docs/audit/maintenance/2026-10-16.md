## Findings addressed

- **Default archive resource bounds:** default ZIP/TAR extraction bypassed the
  bounded implementation used by binary scans. Both now share its entry,
  expanded-byte, compression-ratio, path, and link checks. Rejection fails closed.
  Five regression tests use tiny local fixtures and lowered limits, not large
  resource-exhaustion payloads. This tightens compatibility: ZIP64, multi-disk,
  link-bearing, and over-budget archives are rejected by default too.
- **Audit output filesystem handling:** report writes followed existing file
  symlinks and relied on the caller's umask. Reports now use private temporary
  files and atomic replacement; new final directories are mode 0700 and files
  0600 on POSIX. Default managed directory links and an explicit final output
  directory link are rejected. Four regression tests verify benign sentinels
  stay unchanged and files remain private. Parent directories must remain under
  operator control; this is not a general concurrent-filesystem-race defense.
- **Browser redirect credential scoping:** the new redirect handler compared
  only hostnames and could restore original headers when returning to the initial
  URL. It now compares scheme, hostname, and effective port, and retains stripped
  headers on every later hop. Two mocked-transport regressions cover those
  boundaries. No external target or real credential was used.
